# U2b Replan: Complete the Release Orchestrator in Production Shape

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix the P0/P1 gaps found by independent closeout review (executor evidence + Grok 4.6 xhigh + Gemini 3.1 Pro high + main-thread verification) so U2b can close: strict U1 qualification, deterministic version-only prep, full post-approval immutable publish, canary failure injection + cleanup, job-level concurrency, and whole-repo write-contract tests.

**Architecture:** Keep the existing gate/qualify/rc-pipeline/approval shape. Qualify gains strict U1 automatic qualification (push context from `github.event`, PR lookup, provenance replay) and version derivation. A new `prep` step creates the deterministic version-only commit. `publish` becomes the real post-approval chain (CAS promote → draft+tag → two assets → immutable verify → publish → delivery → update.json → incident). Canary gains injections and `always()` cleanup. Job-level concurrency guards prep mutation and irreversible publish.

**Tech Stack:** GitHub Actions, bash, Python 3 unittest (contract tests), `gh` REST, pinned Actions.

## Global Constraints

- `TVBOX_U2_ENABLED=false` through U2b; only U2c sets `true`.
- No formal `v*`/Release/`update.json` mutation while flag is false.
- N1 deferred to 2026-09-28; exact `known-debt/3` allowlist or `clean/0/[]` only.
- Approval marker binds release-SHA/debt/version/APK-SHA/run/attempt exactly.
- Publish write identity = `TVBOX_RELEASE_TOKEN` (Contents: read+write, single repo); approvals read uses `GITHUB_TOKEN`.
- No whole-run concurrency; job-level `tvbox-u2-prepare` and `tvbox-u2-publish` (queue:max, no cancel).
- All external Actions full-SHA pinned; no unrelated upgrades.
- Tests: 89+ Python tests, py_compile, YAML parse, bash -n, git diff --check all PASS.
- Commit per batch to `patched`; never touch `main`.
